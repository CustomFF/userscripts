# YouTube: Массовое удаление из истории просмотра

[![Install](https://img.shields.io/badge/Install-Direct-brightgreen)](youtube_history_bulk_delete.user.js?raw=1)

YouTube позволяет удалять видео из истории просмотра только по одному, через меню каждого видео.  
Скрипт добавляет чекбоксы и удаляет выбранные видео одной кнопкой.

### Функционал
* Кнопка «Пакетное удаление» в [истории просмотра](https://www.youtube.com/feed/history), рядом с «Очистить историю просмотра» и в том же стиле. Она включает режим выбора и остаётся нажатой, пока он включён; повторное нажатие его выключает.
* В режиме выбора: чекбокс в углу превью каждого видео (страница при этом не сдвигается), выбранные видео обводятся рамкой.
* Shift+клик выделяет (или снимает) диапазон от предыдущего чекбокса.
* Панель внизу справа: счётчик выбранного, «Выбрать все» (все загруженные видео), «Удалить выбранное» с прогрессом.
* Удаление тем же запросом, что и пункт меню «Удалить из истории просмотра», пачками без открытия меню. Если для видео это не сработало, скрипт удаляет его через меню.
* Работает при переходе в историю внутри YouTube, без перезагрузки страницы.
