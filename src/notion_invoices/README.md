# Notion Invoices Bulk Downloader

[![Install](https://img.shields.io/badge/Install-Direct-brightgreen)](notion_invoices.user.js?raw=1)

Массовое скачивание инвойсов и квитанций из Notion Billing одним ZIP-архивом.

### Скриншоты
| До (Before) | После (After) |
| :--- | :--- |

### Функционал
* Добавляет чекбоксы выбора в таблицу истории платежей.
* Кнопка "Download selected" собирает выбранные документы в один ZIP-архив.
